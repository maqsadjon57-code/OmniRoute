# AI Fitness Camera Pro — Онлайн-тренер с монетизацией 0.1₽ за повторение

Облачная фитнес-платформа, использующая камеру и компьютерное зрение (MediaPipe Pose / ML Kit) для распознавания скелета человека, подсчёта повторений и анализа техники в реальном времени.

**Каждое правильно выполненное отжимание = 0.1₽ на баланс** с выводом реальных денег от 100₽. Видео не покидает устройство — на сервер только числовые данные.

## 🚀 Фичи

### AI-камера и скелет
- Полноэкранный видеопоток (задняя/фронтальная) через CameraX
- Наложение скелета: цветные точки и линии (плечи, локти, запястья, бёдра, колени, голеностопы)
- Частота инференса 10–20 FPS, ≤100мс задержка
- Зелёные линии — правильно, красные — ошибки
- Автокалибровка под пользователя

### Подсчёт отжиманий (State Machine UP → DOWN → UP)
- Угол локтя ≤90° внизу и ≥160° вверху, спина прямая <15°
- Фильтр Калмана для сглаживания углов, минимальный интервал 0.5с
- Анализ техники: глубина, спина, локти, полное разгибание
- Поддержка вариантов: классические, с колен, широкий/узкий хват
- Точность ≥95% при правильной установке камеры

### Монетизация
- 0.1₽ за подтверждённое сервером отжимание (0.15₽ премиум)
- Rewarded video AdMob +0.5₽ (лимит 5/день)
- Челленджи, реферальная программа +10₽ за друга, соревнования с призовыми фондами
- Вывод от 100₽ через ЮKassa/Stripe, комиссия 5–10%
- Покупка виртуальных товаров (темы, бейджи), премиум-подписка

### Защита от накрутки
- Серверная валидация каждого повторения
- Лимиты: 1000/день, 5000/неделя
- HMAC подпись запросов, проверка таймстампов, rate limiting
- Детекция аномалий (слишком быстрые повторы, отсутствие вариации углов), ML-детекция ботов
- Верификация телефона/email для вывода, блокировка мошенников

## 🏗 Архитектура

### Поток данных
1. Устройство: кадры → MediaPipe → ключевые точки → локальный подсчёт (RepCounter + Kalman)
2. Отправка на сервер: данные о повторениях (таймстампы, точки, углы) + HMAC подпись
3. Сервер: валидация (repValidator.ts), антифрод, начисление баланса, обновление статистики
4. Ответ: подтверждение, обновлённый баланс, достижения

### Синхронизация
- Все данные в облаке (PostgreSQL + Firestore)
- Room для кэша и кратковременных сбоев
- Автосинхронизация при восстановлении сети

### Безопасность
- HTTPS, JWT, серверная валидация
- Видео не покидает устройство
- Персональные данные шифруются, GDPR удаление аккаунта

## 🔧 Запуск

### Android
1. Открыть `android/` в Android Studio
2. Добавить `google-services.json`
3. Скачать модель `pose_landmarker_lite.task` в `assets/`
4. Запустить на Android 8.0+

### Server
```bash
cd server
cp .env.example .env
docker-compose up -d postgres redis
npm install
npm run dev
# http://localhost:3000/health
# Web демо: http://localhost:3000/
```

Веб-демо использует MediaPipe Web и полностью работает в браузере (для проверки логики без Android).
