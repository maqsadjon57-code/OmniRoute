# OmniRoute — Claude Code Web

Terminal-first AI coding agent in the browser. Dark, monospaced, tool-using, with a permission system and a virtual workspace.

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Open the served URL. Type `/help` or **Ctrl+Shift+P**.

Not affiliated with Anthropic. See `docs/` for shortcuts and the API hook.
