📱 Установка на телефон

3 способа запустить: мгновенно в браузере (QR) или как нативное Android приложение

🚀 Способ 1: Мгновенный запуск (iPhone + Android) — 5 секунд

Работает прямо в браузере, без установки. Использует MediaPipe Web — та же логика что и в Android APK.

Отсканируйте камерой

https://3000-ia98rlr97a8r49bm03emm.e2b.app

Открыть демо
iPhone (Safari):
1. Откройте Камеру → наведите на QR
2. Нажмите на ссылку сверху
3. Разрешите камеру → «Разрешить»
4. Поставьте телефон на пол, отжимайтесь боком к камере

Android (Chrome):
1. Камера или Google Lens → QR
2. Открыть в Chrome
3. Разрешить камеру
4. Отжимайтесь — счётчик и 0.1₽/повтор!

💡 Совет: Поставьте телефон на расстоянии 2-3 метра, чтобы было видно всё тело. Боком лучше для отжиманий.

📦 Способ 2: Нативный Android APK

Полное приложение из ТЗ с CameraX, Room, Hilt, Firebase, AdMob, Billing.

Сборка APK:

cd android
# Добавьте google-services.json в app/
# Скачайте pose_landmarker_lite.task в app/src/main/assets/
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk

# Для QR установки залейте APK в Firebase App Distribution / Diawi
# или запустите локально:
python3 -m http.server 8000
# Откройте http://YOUR_IP:8000/app-debug.apk на телефоне

После установки: дайте разрешения Камера + Уведомления. Логин через Firebase Auth.

Требования: Android 8.0+, 2GB RAM, камера

🍎 Способ 3: iPhone как PWA (Добавить на главный экран)

Веб-демо можно установить как приложение:

  1. Откройте демо по QR в Safari
  2. Нажмите Поделиться → На экран «Домой»
  3. Назовите «AI Fitness» → Добавить
  4. Запускайте с иконки как нативное приложение, fullscreen, без адресной строки

PWA использует тот же MediaPipe, работает офлайн (кэш), видео не уходит с устройства. Для выплат и соревнований нужен онлайн (сервер уже запущен).
