# Keyboard shortcuts

## Core

| Action | Keys |
|--------|------|
| Submit | Enter |
| Newline | Shift+Enter |
| Autocomplete | Tab |
| Previous / next command | ↑ / ↓ |
| Cancel run | Ctrl+C or Esc |
| Clear screen | Ctrl+L |
| Reverse history search | Ctrl+R |
| Command palette | Ctrl+Shift+P |
| Settings | Ctrl+, |
| Search workspace | Ctrl+F |
| Toggle sidebar | Ctrl+B |
| Cycle theme | Ctrl+Shift+T |
| API key | Ctrl+Shift+K |
| Select model | Ctrl+Shift+M |
| Focus composer | Ctrl+I or `/` |

## Tools

| Tool | Keys |
|------|------|
| Read | Ctrl+Shift+R |
| Write | Ctrl+Shift+W |
| Edit | Ctrl+Shift+E |
| Delete | Ctrl+Shift+D |
| Search | Ctrl+Shift+S |
| List files | Ctrl+Shift+L |
| Execute | Ctrl+Shift+X |
| Web fetch | Ctrl+Shift+G |
| Git status | Ctrl+Shift+U |
| Help / shortcuts | Ctrl+Shift+H |
| Web search | Ctrl+Alt+F |
| Browser | Ctrl+Alt+B |

## Composer editing

Standard OS bindings apply for copy / paste / undo. `Tab` inserts spaces when no completion is open.
